## HTTP conventions
Same-origin /api/* JSON, response errors {error:string,code?:string}. POST/PATCH/DELETE require exact allowed Origin plus X-One-Ghana-CSRF header equal to session csrfToken. Auth endpoints handle OAuth state/PKCE independently. Client fetch credentials:same-origin. Routes return Response|null for unhandled. Environment type is SaaSEnv from ./env (root).

GET /api/session => {user:null|{id,email,name,role:'player'|'admin'},csrfToken?:string,configured:boolean}. GET /auth/login => WorkOS Google flow. GET /auth/callback. POST /auth/logout.
Authenticated user contract {id,email,name,role}; auth module exports getSession(request,env): Promise<{user,csrfToken}|null>, requireMutation(request,env,session):void, handleAuth(request,env):Promise<Response|null>.

CampaignRecord {id,revision,state:GameState,eventMode:'classic'|'live',events:CampaignEvent[],createdAt,updatedAt}. CampaignEvent from root contracts. GET /api/campaigns => {campaigns:CampaignRecord[]}; POST /api/campaigns {name?,seed?,importJson?,idempotencyKey} => {campaign:CampaignRecord}. GET /api/campaigns/:id => {campaign}. DELETE same id {expectedRevision,idempotencyKey}. POST /api/campaigns/:id/actions {expectedRevision,idempotencyKey,action:'submit'|'advance'|'branch'|'upgrade'|'accept-event',proposal?,name?,eventId?,eventVersion?} => {campaign:CampaignRecord,report?:TurnReport}; branch/upgrade creates a new owned record, original unchanged. Classic cannot accept events. GET /api/campaigns/:id/export => export JSON text. Engine previews local; root cloud/events helpers prepare pending events for preview/advance (see contracts).
